# Data

This folder contains the curated input data for the stage-resolved transcriptomic analysis of the IL-10 axis in the MASLD/MASH-to-HCC mouse model (GSE246221), as presented in Section 4.2 of the associated Biomedicines paper.

## Files

| File | Size | Description |
|---|---|---|
| `counts_final.csv` | 3.4 MB | Raw gene count matrix (20,100 genes × 40 samples) |
| `cohort_final.csv` | 7 KB | Sample metadata + stage annotation |
| `log_cpm_final.csv` | 15 MB | TMM-normalized log2-CPM expression matrix |
| `signature_panel.csv` | 12 KB | Curated marker gene panels for 4 liver cell types |

## Cohort curation

Starting from the 55 samples in GSE246221 (Jeong et al., 2024), we applied strict metadata curation to obtain a biologically homogeneous trajectory:

- Excluded all pharmacological-intervention samples (Tirzepatide + vehicle controls, n=10)
- Excluded all HFD-only Batch 2 samples (n=5)

Final cohort: **n=40 biologically independent Batch 1 samples** distributed across 6 disease stages:

| Stage | Age | n |
|---|---|---|
| S1_Control_07w (Healthy control) | 7 weeks | 5 |
| S2a_EarlyMASLD_14w (Early MASLD) | 14 weeks | 5 |
| S3_MASH_20w (MASH) | 20 weeks | 5 |
| S4_Fibrosis_32w (Liver fibrosis) | 32 weeks | 5 |
| S2b_ChronicNT_56w (Chronic non-tumor inflammation) | 56 weeks | 6 |
| S5_HCC (Hepatocellular carcinoma) | 44–56 weeks | 14 |

## File details

### `counts_final.csv`

Raw integer count matrix from the GEO GSE246221 study, filtered to the curated n=40 cohort. Rows are genes (indexed by the original Ensembl ID + MGI symbol, e.g., `ENSMUSG00000032089_Il10ra`); columns are the 40 sample IDs matching `cohort_final.csv`.

### `cohort_final.csv`

Sample metadata with one row per sample (n=40). Key columns:

- `column_name` — sample identifier (matches column names in count/log_cpm matrices)
- `GSM` — GEO sample accession
- `batch` — sequencing batch (all = Batch1 after curation)
- `age` — age in weeks at sacrifice
- `diet` — Control or HFD
- `STZ` — streptozotocin treatment status
- `sex`, `genotype`, `strain` — mouse characteristics
- `group` — final stage assignment (one of the six stages above)

### `log_cpm_final.csv`

TMM-normalized log2-CPM values, computed from `counts_final.csv` using the custom Python implementation in `scripts/limma_voom.py` (cross-validated against R limma with Pearson r = 1.000; see `audit/`). Row index and column names match `counts_final.csv`.

This file is **derived** — it can be regenerated by running `python3 scripts/run_deg.py`. It is included in the repository for convenience so that downstream analyses (figures, signature scoring) can be run without first executing the normalization step.

### `signature_panel.csv`

Cell-type marker gene panels used in the signature-enrichment analysis of Figure 4. Columns:

- `signature` — cell type identifier (`Hepatocytes`, `Macrophages_Monocytes`, `NK_cells`, `HSC_Fibrosis`)
- `gene` — MGI gene symbol
- `source` — origin of the marker (CellMarker 2.0, mMCP-counter, or literature-canonical)

The full signature panel with per-gene provenance is also provided in Supplementary Table A3 of the paper. **Note**: this is a signature-enrichment approach, NOT a cell-proportion deconvolution (see paper Section 4.2 and Figure 4 legend for methodological clarification).

## How to use

These files are consumed by the scripts in `../scripts/`. For example:

```bash
# From the repository root
python3 scripts/run_deg.py                    # uses counts_final.csv + cohort_final.csv
python3 scripts/run_celltype_signatures.py    # uses log_cpm_final.csv + signature_panel.csv
```

See the main `README.md` at the repository root for the full reproduction workflow.
