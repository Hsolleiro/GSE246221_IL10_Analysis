# GSE246221_IL10_Analysis

Custom bioinformatic pipeline for the re-analysis of the GEO dataset [GSE246221](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE246221) (Jeong et al. 2024, *Nature Communications*), used in the paper:

> **Hepatocarcinogenesis in the Context of Metabolic Dysfunction-Associated Steatotic Liver Disease: Emerging Roles of Interleukin-10 and Transcriptomic Insights into its Signaling Rewiring**
> Helena Solleiro-Villavicencio, Lucía Angélica Méndez-García, Itzel Baltazar-Pérez, Pablo Fernando Pineda-Pérez, Ana Alfaro-Cruz
> *Biomedicines* (2026) — in press

## Overview

This repository contains the full computational pipeline for Section 4.2 of the paper: stage-resolved transcriptomic analysis of the IL-10 signaling axis in a MASLD→MASH→Fibrosis→HCC mouse model (n=40 biologically independent samples, Batch 1 of GSE246221). The pipeline includes:

- Custom Python implementation of limma-voom (Law et al. 2014) with empirical Bayes shrinkage (Smyth 2004) and robust variance estimation (Phipson et al. 2016).
- Cross-validation against PyDESeq2 (Muzellec et al. 2023).
- Cell-type signature enrichment across 4 hepatic compartments (Hepatocytes, Hepatic Stellate Cells, NK cells, Macrophages/Monocytes) using CellMarker 2.0 references (Hu et al. 2023).
- Full methodological audit against the reference R implementation (limma v.3.62+, Bioconductor) — see `audit/` directory.

## Key methodological validation

The custom Python limma-voom implementation was independently validated against the reference R implementation (limma v.3.62+, Bioconductor) using `rpy2` on the same n=40 cohort. Across the six pairwise stage contrasts (20,100 genes each):

| Metric | Result |
|---|---|
| Pearson r of log2FC estimates | **1.000** in all 6 contrasts |
| Spearman rank correlation | 0.9993 – 0.9995 |
| Top-100 gene overlap | 91 – 100 / 100 per contrast |

Cross-validation against PyDESeq2 (Wald test on rounded counts) showed Pearson r = 0.88 – 0.98 in log2FC estimates. Full validation notebook: [`audit/audit_colab_notebook.ipynb`](audit/audit_colab_notebook.ipynb).

## Cohort composition

40 biologically independent samples (Batch 1 of GSE246221), distributed across six histologically annotated stages:

| Stage | Age (weeks) | n |
|---|---|---|
| Control (healthy) | 7 | 5 |
| Early MASLD | 14 | 5 |
| MASH | 20 | 5 |
| Fibrosis | 32 | 5 |
| Chronic inflammation, non-tumor | 56 | 6 |
| HCC | 44 – 56 | 14 |

Pharmacological-intervention samples (Tirzepatide + matched vehicle, n=10) and HFD-only Batch 2 samples (n=5) were excluded during curation to isolate the natural MASLD→HCC trajectory. See `results/supplementary/TableA1_cohort.csv` for per-sample metadata.

## Quickstart: reproduce the analysis

### Prerequisites

```bash
python3 -m pip install numpy pandas scipy statsmodels pydeseq2 matplotlib openpyxl python-docx
```

### Run the full pipeline

```bash
# 1. Differential expression (6 contrasts + F-test)
python3 scripts/run_deg.py

# 2. Cross-validation with PyDESeq2
python3 scripts/run_deseq2.py

# 3. Cell-type signature enrichment
python3 scripts/run_celltype_signatures.py

# 4. Generate figures
python3 scripts/make_figure2.py
python3 scripts/make_figure3.py
python3 scripts/make_figure4.py

# 5. Build supplementary materials
python3 scripts/build_supplementary_tables.py
python3 scripts/build_supplementary_methods.py

# 6. (Optional) Internal methodological audit
python3 scripts/audit_methods.py
```

All inputs are in `data/`, all outputs are re-generated into a local `results/` directory. The `results/` subfolders in this repository are not committed to keep the repo lightweight — running the scripts above reproduces them exactly.

## Data sources

- **Raw data**: GEO [GSE246221](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE246221) (Jeong et al. 2024)
- **Cell-type markers**: [CellMarker 2.0](http://bio-bigdata.hrbmu.edu.cn/CellMarker/) (Hu et al. 2023) supplemented with canonical hepatic references (Halpern 2017, Mederacke 2013, Remmerie 2020)
